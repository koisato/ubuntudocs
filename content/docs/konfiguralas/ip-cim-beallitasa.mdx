## IP cím beállítása

Mivel a telepítőben nem adtunk meg IP címet vagy DHCP-t, ezt most fogjuk megcsinálni.

- Először is kapcsoljuk fel az interface-t:

```bash
sudo ip link set enp0s3 up
```
- Ez után hozzuk létre a Netplan configot:

```bash
sudo nano /etc/netplan/01-netcfg.yaml
```
- Ebbe a fájlba amit megnyitottunk, írjuk a következőket (a saját IP címmel amit kaptunk):

```bash
network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: false
      addresses:
        - 192.168.1.108/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1
```

- Mentsük el a configot, majd alkalmazzuk a beállításokat:

```bash
sudo netplan apply
```
- az "ip a" parancsra megjelennek a beállítások, ellenőrizzük őket.
