## Samba telepítése

```bash
sudo apt install samba -y
```

---

## Mappa létrehozása:

```bash
sudo mkdir -p /srv/samba/share
```

---

## Jogosultságok megadása:

- a 775 a tulajdonosnak teljes jogot biztosít, a groupnak szintúgy, mindenki másnak csak read és execute jogaik vannak. (rwx rwx r-x)

```bash
sudo chown peti:peti /srv/samba/share
sudo chmod 0775 /srv/samba/share
```

---

## Samba config file szerkesztése

- Először nyissuk meg a fájlt

```bash
sudo nano /etc/samba/smb.conf
```

- Majd szúrjuk be ezt a végére:

```bash
[share]
   path = /srv/samba/share
   browseable = yes
   writable = yes
   read only = no
```

- Ellenőrizzük le a configot. Ha nincs error, jók vagyunk.

```bash
testparm
```

---

## User létrehozása

- A command után a terminál kérni fog egy jelszót. Ajduk meg, erősítsük meg, és kész a felhasználónk.

```bash
sudo smbpasswd -a peti
```

---

## Újraindítás és ellenőrzés

- Indítsuk újra a Samba-t

```bash
sudo systemctl restart smbd
```

- Ellenőrizzük hogy megy-e

```bash
systemctl status smbd
```

---

## Tesztelés

- Windows Explorer címsorába írjuk be a következőt:

```bash

```
