## Setting the IP address

Since we didn't set an IP address or DHCP in the installer, we'll do it now.

- First, bring the interface up:

```bash
sudo ip link set enp0s3 up
```
- Then create the Netplan config:

```bash
sudo nano /etc/netplan/01-netcfg.yaml
```
- Write the following into the file we just opened (with the IP address you were given):

```bash
network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: false
      addresses:
        - 192.168.1.108/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 192.168.1.108
```

- Save the config, then apply the settings:

```bash
sudo netplan apply
```
- The "ip a" command shows the settings, so check them.
